# 🎗️ Breast Cancer Prediction

A Machine Learning project for breast cancer classification using Python and Scikit-learn.

## 📌 About the Project

This project uses the Breast Cancer Wisconsin (Diagnostic) dataset to classify tumors as **malignant** or **benign**.

The project includes data exploration, preprocessing, feature scaling, model training, prediction, and model performance comparison.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Models

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Random Forest

## 📊 Dataset

The project uses the Breast Cancer Wisconsin (Diagnostic) dataset available through Scikit-learn.

- 569 instances
- 30 numerical features
- Target classes: Malignant and Benign
